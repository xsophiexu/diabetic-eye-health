# Diabetes & Your Eyes

A small static website with plain-language resources about vision loss caused by diabetes: diabetic retinopathy, diabetic macular edema, cataracts, and glaucoma, plus warning signs, prevention, screening schedules, treatment options, and links to trusted organizations (NEI, CDC, ADA, AAO, MedlinePlus, Prevent Blindness).

## Run locally

Open `index.html` in a browser. No build step.

## Publish with GitHub Pages

Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)`.

## Disclaimer

For general education only. Not medical advice.
